摘 要：本论文聚焦竖屏微短剧，在当前新媒体蓬勃发展的背景下，探讨竖屏微短剧的兴起。本文界定了竖屏微短剧的基本定义，阐述其分类包括男频剧和女频剧及其各自特点。深入剖析其叙事策略，如快节奏、单线叙事、强烈冲突、碎片化结构、类型化及轻量级情感表达等，同时分析适应竖屏的视听语言，包括构图、景别、镜头运动和场景设计等方面。同时竖屏短剧也面临同质化研究的挑战，其未来发展需在创新内容、提升品质等方面着力，学界也应加强研究以促其持续发展。

关键词：微短剧；竖屏微短剧；叙事策略

<a id="s01"></a>
## 绪论

随着互联网技术和移动电子设备的迅猛发展，人们的娱乐形式也随着媒介的改变而不断变化。5G技术的不断普及也为人们带来了高速的网络，随时随地获得高清的视频娱乐。并且随着短视频的崛起，用户的碎片化观看成为习惯。现代社会节奏的加快，使得传统的长篇剧集开始流失掉一定的受众，因为紧张的生活节奏已经无法适应“慢”叙事。观众渴望在短暂的时间内获得更快更丰富的信息和娱乐。微短剧的出现巧妙的符合了现代人的观看需求。并且随着手机的普及速度和竖屏的使用习惯，使得竖屏形式的微短剧在短剧这个大类中，占据着更多的内容和传播量。2020年微短剧正式被国家广电总局类入除网络剧，网络电影，网络动画片之外的第四个类别。随着微短剧的爆火，越来越多的拍摄传统影视的影视行业人员涌入拍摄微短剧的赛道。横店被业界戏称为“竖店”。这是因为在横店的酒店，影视城，摄影棚每日将近100个短剧剧组同时开机拍摄竖屏短剧。相较于传统的电视剧和电影，制作团队往往需要面对高额的制作成本和巨大的市场风险。对于新兴的网络影视制作公司和一些中小规模的制作团队来说，微短剧成为了一个进入市场的突破口。它的制作成本相对较低，制作周期短，可以更快地推出作品，同时也能满足平台对于内容数量和多样性的要求。从几年前爱奇艺《生活对我下手了》的初步尝试，到今天抖音、快手等超级短视频平台的大力推送，无论从生产规模、戏剧特征、制作手段还是传播效果来看，竖屏微短剧都已然成为一种全新的网络剧形式。$^{[1]}$

故本文依托火爆的微短剧市场，深入剖析竖屏微短

剧叙事结构、节奏与视听元素的特点，包括镜头语言、叙事模式等，揭示其独特性。从理论层面丰富影视研究内容，为理解新媒体时代下的叙事和视听创新提供案例。实践上，指导竖屏微短剧创作优化，助力创作者更好地把握受众心理，推动影视行业在叙事和视听方面适应新趋势发展。

## 一、竖屏微短剧的定义与分类


> 本节原提取未包含可核验的正文；仅保留定位，不作为完整知识条目。

<a id="s03"></a>
## （一）定义界定

微短剧是一种新兴的影视艺术形式，它融合了传统影视剧与现代互联网内容传播特点。2020年8月，国家广播电视总局将微短剧定义为单集时长10分钟以内的网络影视剧。网络微短剧不仅借由生产主体的泛众化，以平民的视角、微小化的事件、内化的表达为精英文化“去蔽”$^{[2]}$。竖屏微短剧是微短剧在呈现形式上的一种创兴和细分。首先，它以竖屏作为主要展示方式，这是为了更好地适配移动设备，如智能手机的使用习惯。在移动互联网时代，人们手持手机观看视频的场景极为普遍，竖屏观看无需旋转设备，操作更加便捷，符合用户的自然使用状态。由于目前学界对于微短剧并没有一个明确的界定，故笔者在此给出大概的界定：竖屏短剧是一种单集时长多为1至2分钟，总集数几十集到百集不等的剧目，以竖屏形式播放，通常在小程序平台、抖音、快手等平台上播出。每一集的结尾通常会留下悬念或卡在剧情的关键点，以吸引观众继续观看。

<a id="s04"></a>
## （二）竖屏微短剧的分类

在竖屏微短剧这一新兴的影视领域中，依据目标受众的性别差异，出现了男频剧和女频剧的分类方式。依

据笔者的调查的某一年度的统计表上显示，虽然有着不同的类型模式，但是男频剧，女频剧的区分依旧是竖屏短剧的重要分类方式。

男频竖屏短剧主要分为“霸道总裁”“战神”和“赘婿”等类型。内容以“逆袭”和“重生”为主题，强调一个“爽”字$^{[3]}$。具体来说，这些短剧通常讲述的是底层人物通过某种方式获得财富、地位或能力，进而实现人生的转变。以由蜜糖短剧和西安丰行文化联手打造的男频短剧《无双》为例，上线48小时内就创下了5500万的收入，堪称短剧史上的现象级男频作品。《无双》主要剧情为男主楚青是龙殿殿主的继承人，但他为了报答沈雨宁的救命之恩，一直隐藏身份，以普通人的身份待在她身边。沈家所有的成功其实都是楚青默默支撑的，但当沈雨宁地位飞升后，她却选择抛弃楚青。此剧主要以“逆袭”和打脸的剧情，不断调动观众的好奇情绪和“逆袭”后的爽感。

女频短剧是指主要面向女性观众群体的短剧作品。这类短剧通常聚焦于爱情、职场、家庭等生活领域，并且特别注重角色之间的情感交流和个人成长经历。女频短剧往往包含了一些特定的元素或情节模式，比如“虐妻一时爽，追妻火葬场”、“霸道总裁爱上我”或者“大女主复仇手撕渣男”等，这些都是为了吸引特定的女性受众而设计的情节桥段。比如大女主复仇爽剧《引她入室》，一度冲上微博热搜，霸榜短剧热度榜。故事讲述的是一位名为郑萋的令人艳羡的家庭主妇，有着身为世界五百强的副总的丈夫吴池，和刚刚上幼儿园听话懂事女儿，本以为自己的生活甜蜜而安逸，但却发现一她的丈夫出轨了。这部剧可以说是为短剧精品化面临的难以兼顾“爽感”与高立意的难题提供了解题思路。以“爽”开始，以女性互助、女性成长所表达的爱与温暖结束。

## 二、竖屏微短剧的叙事策略

<a id="s06"></a>
## （一）快节奏的叙事

由于每集通常只有几分钟，竖屏短剧的叙事必须高度凝练，几乎没有时间进行冗长的铺垫。故事情节迅速展开，情感张力在短时间内迅速上升和解决。每集都有一个明显的戏剧高潮，让观众在短短几分钟内获得情感的起伏和满足。竖屏短剧很少花费时间进行背景设定或世界观的铺陈，通常依赖观众的常识或直接的视觉信息来迅速构建情境。情节开头往往直接进入核心冲突或事件，避免冗长的序幕，确保迅速抓住观众注意力。

<a id="s07"></a>
## （二）单线叙事为主

竖屏短剧通常采用单线叙事，即以一个主线故事为

核心，围绕一个事件、关系或冲突展开叙述。这种单线叙事方式简化了剧情结构，避免了复杂的多线叙事对时长的要求。大部分短剧集中在一个核心问题上，迅速引出问题、展开冲突，并尽可能在每集内完成情节的小高潮或悬念。

<a id="s08"></a>
## （三）强烈的戏剧冲突

竖屏短剧注重在有限时间内制造冲突，以增强剧情的紧张感和观众的代入感。常见的冲突类型包括：家庭或情感冲突：许多短剧围绕家庭关系、爱情、友情等展开，情感矛盾往往直观明了，容易引发观众共鸣。身份转换或角色转变：通过角色的身份变化或情境的突变（如突然的逆袭、转折或发现秘密），推动故事向高潮发展。

<a id="s09"></a>
## （四）碎片化的剧情结构

竖屏短剧通常是以分段的形式展现较长的故事，但每一段（或每一集）又具有相对独立的剧情。观众即使没有连续观看所有集数，也能从某一集中获得完整的剧情体验。这种碎片化的结构为观众提供了灵活的观看体验，适应了移动端的碎片化消费习惯。

<a id="s10"></a>
## （五）高度类型化的叙事

竖屏短剧经常依赖高度类型化的剧情模式，来迅速与观众建立认知上的联系。常见的类型包括-喜剧：通过夸张的情节、幽默的对话和轻松的情境设定吸引观众，故事节奏快速轻松。爱情故事：爱情题材常见于竖屏短剧，因其情感张力易于在短时间内展现。通常是简单的“遇见—冲突—解决”的结构。职场逆袭或家庭逆袭：主人公在短时间内从困境中脱身，实现逆袭。这类剧情容易引发观众的代入感和满足感。

<a id="s11"></a>
## （六）轻量级的情感表达

竖屏短剧多采用直白、简单的情感表达方式，避免复杂的心理刻画或深度的情感探索。由于时间短，角色的情感状态和转变往往通过显性化的方式表现出来，如直白的台词、夸张的表情和动作，或者通过情节的迅速转折来直接展现角色情感的变化。

<a id="s12"></a>
## 三、竖屏短剧的视听语言

竖屏短剧由于其专为移动端竖屏观看而设计，在构图、景别和镜头运用上与传统影视作品有显著不同。这些独特的视觉语言选择不仅要适应竖屏的比例，还要强化故事的叙事效果，使观众能够在移动设备上获得更加沉浸的体验。

<a id="s13"></a>
## （一）竖屏的构图

竖屏的比例通常为9：16，这与传统影视中的16：9横屏比例完全相反。因此，竖屏短剧在构图时必须根据

这一限制进行调整。竖屏的垂直构图可以突出纵向空间，将角色从头到脚置于画面中心，这种构图方式往往让观众感觉更接近角色，增强情感连接。它可以很好地表现单人场景，尤其是在角色情绪表达、面部特写和独自行动的场景中，竖屏能增强观众的代入感。在竖屏短剧中，人物通常会被放置在画面的中央或稍偏下的位置，以符合人眼在竖屏观看时的视觉习惯。由于屏幕的宽度有限，多人场景中的角色可能需要通过纵向排列或者更紧密的构图方式展现，减少横向空间的浪费。例如，两个人物对话时常常会通过分屏或快速切换镜头来表现对话，而不是采用横向的双人同框。由于竖屏限制了横向空间，创作者需要通过纵深来增强画面的视觉效果。纵深构图可以在狭窄的画面中制造层次感，如通过前景、中景、远景的排列，给画面注入深度。比如，人物在走廊、街道等纵深感较强的场景中行走时，竖屏能够更好地捕捉这种运动感。

<a id="s14"></a>
## （二）景别的选择

由于竖屏的限制，近景和特写镜头在竖屏短剧中尤为常见。这些镜头能够将角色的面部表情和细节直接呈现在观众面前，形成强烈的情感冲击。竖屏的垂直构图让面部特写变得更加具有视觉冲击力，尤其是在对话、情感爆发等戏剧性场景中，近景和特写可以让观众更直观地感受到角色的情绪波动。竖屏较适合拍摄单人全身镜头，因为人物可以在垂直空间内完全展示。在传统影视中，中景或远景可能横向展示多个角色或场景细节，而竖屏短剧在使用中景时，常常会将人物放在画面中央，环境的展示被压缩至最少，环境通常只作为背景而非主体。例如，人物站立、行走等动作在竖屏中更适合通过全身镜头表现，而竖屏中景则会较少展示环境的横向广度。竖屏短剧中较少使用传统的广角远景镜头，因为竖屏难以很好地表现开阔的空间感。即使需要展示环境或空间，创作者会倾向于通过俯拍或仰拍等纵向构图方式来表现。例如，俯拍可以展现一个高楼的全貌，而仰拍则可以表现高大的建筑物或者强调角色的渺小和孤独感。

<a id="s15"></a>
## （三）镜头运动与视角选择

在竖屏短剧中，推镜头和拉镜头的应用尤为常见，特别是在角色情绪变化或场景转换中，推镜头可以让观众更快地进入角色内心，拉镜头则可以在有限的空间中展示更多场景内容。

垂直运动（如上下移动镜头）在竖屏中显得更自然且有效。例如，当人物从上方走下楼梯或从下方仰视高

楼时，竖屏能够充分利用这种垂直运动来增强画面的动态感。对比之下，横向的运动（如横移镜头）在竖屏短剧中不常用，因为横向运动在竖屏中难以展现完整的空间感。

竖屏短剧有时会使用主观视角镜头，这种视角模拟了观众的第一人称视角，增强了与剧情的互动性和代入感。竖屏的垂直构图让观众有种“面对面”与角色交流的感觉，尤其适合表现对话和情感交流。通过这种视角，竖屏短剧能够更好地引发观众的情感共鸣。

<a id="s16"></a>
## 总结

竖屏微短剧在新媒体时代的浪潮中异军突起，其独特的叙事策略和视听语言既适应了当下观众的观看习惯和审美需求，又为影视行业带来了新的创作思路与发展机遇。通过快节奏叙事、单线叙事、强烈戏剧冲突、碎片化结构、高度类型化以及轻量级情感表达等叙事策略，竖屏微短剧在有限的时间内成功吸引观众的注意力并引发情感共鸣。在视听语言方面，竖屏构图、特定景别选择、镜头运动与视角运用以及场景设计与美术布景的独特处理，使其在移动设备上呈现出别具一格的视觉效果，增强了观众的沉浸感。然而，竖屏微短剧在蓬勃发展的过程中也面临着诸多挑战。例如，如何在高度类型化的模式中进一步创新剧情以避免同质化，如何在追求快速节奏的同时深化主题内涵，以及如何在适应碎片化观看的基础上提升作品的艺术品质等。未来，随着技术的不断进步和观众审美水平的持续提高，竖屏微短剧有望在保持自身特色的基础上不断优化和创新。创作者应更加注重内容的深度挖掘，在叙事上突破现有模式，在视听语言上进一步探索与创新，以创作出更多高质量、富有创意的作品，推动竖屏微短剧在影视艺术领域持续发展，为观众带来更为丰富和优质的视听体验，也为影视文化的多元化发展贡献力量。同时，学界也应加强对竖屏微短剧的研究，为其健康发展提供理论支持和指导。

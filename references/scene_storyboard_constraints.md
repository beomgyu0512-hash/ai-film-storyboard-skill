# 幕级分镜交付与检查约束

## 一、文件与镜头排版

- 同一幕的所有分镜保存在同一个 MD 文件中，替代此前“每镜一个 MD”的安排。
- 每镜使用明确标题“第1镜”“第2镜”依次编号，并完整套用用户提供的分镜模板，写明镜头时长和切点。
- 两镜之间空两行，插入独立一行“————————————”，再空两行。
- 用户指定本幕“第几镜”时，读取该镜及理解它所需的本幕上下文，按指定范围处理。

排版示意（括号内容为填写说明）：

```markdown
（此处填写检查状态；检查完成前不预填完成标记）

# 第X幕｜幕名

## 第1镜
（完整套用分镜模板）


————————————


## 第2镜
（完整套用分镜模板）
```

## 二、检查顺序与状态

先按顺序检查一致性第1—4项，再按顺序检查观众体验第1—5项。必须逐项检验，完成当前项后再进入下一项，不用整体印象代替逐项判断。

依据本幕分镜、对应戏剧任务、导演方案及已确认内容检查；涉及跨幕承接时核对相关前后内容。缺少必要依据时，在对应项标明“待核验”及缺失内容。

每项记录“未发现问题／有问题／待核验”；没有适用对象时写明“不适用”及原因。问题按“镜号或具体位置 → 可观察表现 → 对理解或感受的影响”说明。

两类检查均逐项完成后，在本幕 MD 最上方标注：

已完成一致性检验✅ 已完成观众体验检验✅

完成标记表示已完成检查，不表示没有问题。发现问题时，在该行下方列出检查类别、项号、镜号、问题及依据；存在待核验项时，对应类别标“待完成一致性检验”或“待完成观众体验检验”，不标完成。

文字分镜的观众体验判断标明“文字预判”；已有动态分镜或成片时，注明实际检查的素材版本。检查结论针对本次版本；修改后复查受影响项并更新状态。

## 三、一致性检查：按以下四项依次检验

### 1. 情节与人物

检查事件因果、时间顺序、人物动机及已知信息是否成立。

- 事件是否有前因，人物行动是否符合当前目标、处境和已知信息。
- 人物是否使用了尚未获知的信息，或无依据地忘记已知事实。
- 前后时间和情节状态是否矛盾；情绪转折是否有触发依据。

问题须指出相互矛盾的内容及其位置。本项判断故事内部是否成立。

### 2. 层间落实

对照已确认的叙事层和导演层交接内容，检查下游是否准确落实上游。

- 导演方案是否保留已定事件、冲突和情绪转折。
- 分镜是否落实已定信息揭示、表演停顿与期待的观众感受所对应的表达安排。
- 是否遗漏、改变或擅自增加已确认范围之外的内容。

问题须指出上游要求及对应分镜的遗漏或偏差。本项检查落实关系；实际能否产生预期感受由观众体验检查判断。

### 3. 空间与动作

检查人物位置、视线、运动方向、动作起止及前后镜衔接。

- 人物位置、朝向、视线目标和进出画方向能否由同一空间关系解释。
- 切换机位后，轴线与方向是否仍可理解；有意换侧是否有清楚的过渡依据。
- 前镜结束动作与后镜起始动作能否衔接，是否无意重复、跳过或重置动作。

问题须定位到具体镜头或相邻镜头，并说明哪一处位置、方向或动作不成立。

### 4. 资产与声音

检查人物外观、道具状态、环境与声音的变化是否有依据。

- 人物服装、发型、伤势等状态是否连续。
- 道具的数量、归属、持用和损坏状态是否连续；涉及动作路径的部分归第3项。
- 环境、光源和天气变化是否符合当前场景与时间。
- 对白、环境声、音效或音乐的出现、消失与跨镜承接是否符合既定安排。

问题须写明变化前后状态及缺失的变化依据。本项判断状态连续性，不评价声音是否具有感染力。

## 四、观众体验检查：按以下五项依次检验

### 1. 能否看懂

检查观众在当前时刻是否已获得理解事件所需的信息。

- 关键人物、目标、行动和后果是否有足够的可见或可听依据。
- 理解某个转折需要的信息是否在适当时点出现。
- 区分刻意保留的悬念与导致基本情节无法理解的信息缺失。

指出观众在哪一镜可能无法理解什么，以及缺少哪项依据。

### 2. 情绪是否有铺垫

对照本幕戏剧任务和期待的观众感受，检查情绪变化是否有表达支撑。

- 期待、压力、转折或释放是否由具体事件、人物表演或视听安排建立。
- 情绪变化前是否有必要铺垫，变化后是否有可辨认的反应。
- 是否只写“感动、紧张、爽”等标签，却缺少能产生这种感受的内容。

指出预期感受、已有表达与缺口；文字阶段只能预判，不将预期写成真实观众反馈。

### 3. 节奏是否合适

检查镜头时长和切点是否给动作、对白、信息辨认及反应留下空间。

- 必须先后发生的动作能否在分配时间内完成。
- 对白、关键表情或线索是否有足够的呈现和辨认时间。
- 是否存在没有叙事或情绪作用的重复、停留，或过早切断必要反应。

指出具体镜头的时间安排或切点及其影响，不以固定快慢标准判断所有题材。

### 4. 是否想继续看

检查本幕与后续内容之间的期待是否成立。

- 未解决的问题、人物处境或后续期待是否清楚。
- 期待是否由本幕已有内容引出，观众是否有理由关心结果。
- 幕末是否承接已定戏剧任务；集末钩子按叙事层已定安排检查，不要求每幕另造钩子。

指出观众可能期待的具体后续及其依据；若本幕承担收束功能，按既定收束任务判断。

### 5. 重点是否突出

检查关键动作、表情或线索在画面与声音中是否容易被注意到。

- 景别、构图、焦点、遮挡和声音是否支持当前注意重点。
- 背景运动、对白、音乐或其他元素是否抢走必要注意。
- 切镜前后注意力能否到达应看的对象。

指出重点对象、干扰来源或呈现不足。本项判断信息是否显著可辨；信息是否已提供由第1项判断，时间是否足够由第3项判断。

## 五、问题反馈

发现问题先明确输出问题所在，再定位最早出错的层。先说明表现和判断依据；无法确定原因时标为“原因假设”，避免直接重写。

按已定修改边界处理：涉及已确认内容时提出修改建议，交由用户决定。获准修改后调用对应层，复查受影响的上下游内容，并在专门的修改记录 MD 中记录：

问题表现 → 所属层与依据 → 修改内容 → 修改后结果 → 是否值得改系统规则。

同一问题涉及多项时，只完整描述一次，其他项引用该问题。

# 知识库调用规则

## 1. 先读任务与交接，再查资料

读取当前情节、进入层级、上一层成果及已确认内容，明确本次需要解决的问题。资料用于解决该问题，不据资料另起创作目标。

## 2. 优先查本层相关章节

先查看本层索引，再读取相关章节正文；不能只凭标题或索引摘要下结论。需要其他层知识时，查对应章节。跨层查阅不等于获得跨层修改权限。

只加载与当前问题有关的内容，不默认通读整个知识库。

## 3. 已确认设定和用户要求优先

资料中的常见结构、节奏、镜头方法均作为参考，不自动成为强制规则。发现资料建议与已确认内容冲突时，说明冲突及影响，不自行覆盖。用户要求彼此冲突时，列明冲突，不自行选择。

## 4. 保留适用条件与出处

采用观点时，记录资料名、章节及本次用途；同一出处可合并记录，不必每镜重复。

判断其题材、媒介、场景与目标是否适用。单一案例不能直接当作跨题材通则；原文未说明适用条件时，不替作者补造结论。

## 5. 找不到依据就说明缺口

区分“资料没有相关内容”和“文件缺页、缺图或提取残缺”。只有摘要，不引用为全文论证；未看到图片，不声称完成图像分析。

模型提出的创作判断明确标为“建议”；原因尚未确定的判断标为“原因假设”，不写成知识库结论。
